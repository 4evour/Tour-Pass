## Recommended Product Boundary

保留：目的地、日期/天数、同行人、节奏、预算、必去地点、交通、行动需求、每日时间轴、地点卡片、地图入口、证据状态、修改/保存。

暂不做：航班比价、酒店库存、预订支付、签证 Agent、独立文化 Agent、独立预算 Agent、图片生成流水线、全局多 Agent 聊天。

## Recommended Frontend Shape

```text
规划前：单一输入页
  目的地 + 你在意什么
  补充条件（抽屉）

生成中：四阶段轻进度
  整理需求 → 查地点和路线 → 排每天 → 检查可行性

生成后：全宽旅行手册
  [目的地/日期/路线一句话/可信状态]
  [今天] [第 2 天] [第 3 天]
  [时间轴：地点 / 交通 / 吃饭 / 休息]
  [依据与待确认] [住宿与预算] [分享/导出]
```

视觉上可保留 Tour Pass 的深绿作为识别色，但把大面积装饰圆环、内部模型选择器、完整度数字和技术说明退到次要层；首屏用目的地图片或真实地点卡片建立旅行感，日程卡负责可执行性。

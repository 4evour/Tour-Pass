**解决方案**：

#### 2. POI 名称显示（P1）
**问题**：地图上只显示圆点，不显示景点名称
**解决方案**：
- 自定义 Marker 组件，显示序号+名称
- 根据缩放级别调整显示方式
- 高亮当前编辑的景点

**技术实现**：
```typescript

```

#### 3. 时间轴视图（P1）
**问题**：缺少直观的时间轴展示
**解决方案**：
- 新增 Timeline 组件
- 显示每个景点的到达/离开时间
- 支持拖拽调整时间

#### 4. 编辑历史面板（P2）
**问题**：无法查看编辑历史
**解决方案**：
- 显示最近的编辑操作列表
- 支持点击回退到任意历史状态
- 显示修改前后的对比

## v4.7 酒店系统完善（P1）

### 目标
完善酒店推荐和锚点系统。

### 功能列表

#### 1. 酒店锚点逻辑（P1）
**问题**：酒店没有真正作为行程锚点
**解决方案**：
- 每天自动计算：酒店 → 景点 → ... → 酒店
- 通勤时间基于酒店位置计算
- 支持单日酒店覆盖

#### 2. 酒店推荐增强（P1）
**问题**：推荐信息不够丰富
**解决方案**：
- 显示酒店评分和评论数
- 显示酒店设施列表
- 显示酒店位置与景点的距离
- 按价格/评分/距离排序

#### 3. 入住区域推荐（P2）
**问题**：不知道住哪里方便
**解决方案**：
- 基于景点分布推荐入住区域
- 显示每个区域的优缺点
- 地图上高亮推荐区域

### 任务分解

| 任务 | 优先级 | 预计时间 | 依赖 |
|------|--------|----------|------|
| 酒店锚点逻辑 | P1 | 2天 | hotelStore |
| 酒店详情展示 | P1 | 1天 | TripAdvisor API |
| 入住区域推荐 | P2 | 2天 | 景点数据分析 |

# Tour Pass 前端重设计 - 左侧导航 + 结构化表单

## 概述

将 Tour Pass 现有单页顶部导航布局重构为**左侧导航栏 + 右侧内容区**的应用布局（参考 Tour-AI 风格），重点优化 AI 行程生成界面的结构化表单，使其更直观、美观。

## 设计决策汇总

| 决策项 | 选择 |
|--------|------|
| 配色方案 | 翡翠旅途 (Emerald Journey) — 白底 + 翡翠绿 (#059669) + 琥珀色 (#f59e0b) |
| 布局结构 | 左侧导航栏 (240px) + 右侧内容区 |
| AI 规划表单 | 单页结构化表单（不分步） |
| 技术栈 | 原生 HTML/CSS/JS，无新框架依赖 |
| 设计定位 | 竞赛展示 + 真实用户双目标 |
| 内容策略 | 网站只讲用户体验，技术细节放 GitHub README |

### 表单控件详细设计

#### 📍 目的地城市（必选）
- **控件类型：** 卡片网格（4 列 × N 行）
- **每张卡片：** emoji + 城市名 + 一句话标签（如 "🐼 成都 · 美食天堂"）
- **交互：** 点击选中（绿色边框 + 浅绿背景），支持单选
- **数据源：** 从 `/cities` API 动态加载

#### 📆 游玩天数
- **控件类型：** 大数字按钮组
- **选项：** 2天 / 3天 / 4天 / 5天 / 6天 / 7天
- **默认值：** 3天
- **交互：** 点击选中，圆形按钮带数字

#### 👥 出行人群
- **控件类型：** 图标 chip 组
- **选项：** 🧑 一个人 / 💑 情侣 / 👨‍👩‍👧 家庭亲子 / 👫 朋友 / 👴 带长辈
- **默认值：** 无（需选择）

#### 🎯 旅游侧重
- **控件类型：** 横向 chip 按钮组
- **选项：** ⚖️ 均衡 / 🏛️ 文化 / 🍜 美食 / 🌿 自然 / 📸 拍照
- **默认值：** 均衡
- **交互：** 单选 chip

#### ⏱ 节奏
- **控件类型：** 三档滑块
- **选项：** 轻松 ← 适中 → 紧凑
- **默认值：** 适中

#### 💰 预算
- **控件类型：** chip 按钮组
- **选项：** 不限 / 💰 经济 / 💰💰 中等 / 💰💰💰 高端
- **默认值：** 中等

#### 🏨 酒店每晚预算
- **控件类型：** 双输入框（最低 - 最高）
- **单位：** 元
- **可选：** 留空表示不限

#### ⭐ 必去景点
- **控件类型：** tag input + 自动补全
- **交互：** 输入时从 POI 库搜索匹配，选中后显示为 tag
- **可选：** 留空表示不指定

#### 📝 特殊要求
- **控件类型：** 多行文本框
- **placeholder：** "例：想住天河区，第三天下午想购物"
- **可选：** 留空表示无特殊要求

### 表单提交

- **按钮：** "🤖 开始 AI 智能规划"，翡翠绿渐变背景
- **提交后：** 按钮变为加载态 "⏳ 规划中..."
- **结果展示：** 表单下方区域，SSE 流式渲染行程结果
- **保留：** 现有的自然语言输入模式作为备选（tab 切换）

## 技术实现要点

### 文件结构
- 重构 `web/index.html`：添加侧边栏 + 路由容器
- 新增 `web/css/sidebar.css`：侧边栏样式
- 新增 `web/css/plan-form.css`：AI 规划表单样式
- 修改 `web/app.js`：添加路由切换逻辑
- 保持 `web/editor/` 编辑器不变，通过"行程编辑器"导航项嵌入

### 路由方案
- 单页应用，hash 路由：`#/plan`、`#/trips`、`#/editor`、`#/xhs`、`#/profile`、`#/contact`
- 默认页：`#/plan`（AI 规划）
- 侧边栏点击切换内容区，不刷新页面

### 行程编辑器集成
- "行程编辑器"导航项直接链接到现有 `web/editor/` 页面
- 新增"导入行程"功能：从"我的行程"页面选择已有行程导入编辑器
- 实现方式：通过 URL 参数 `?tripId=xxx` 传递行程 ID

### 小红书解析（预留）
- 导航项显示"即将上线"标签
- 点击后显示 placeholder 页面："功能开发中，敬请期待"
- 预留 API 接口定义，后续实现时直接对接

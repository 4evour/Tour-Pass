# Tour Pass 简历表达草稿

## 项目名称

C++ AI 城市自由行行程规划引擎

## 项目描述

基于 C++17 开发面向自由行场景的城市多日行程规划算法服务，将景点、餐厅、酒店和夜间活动点建模为带时间窗约束的 POI 图，结合 Dijkstra 最短路、兴趣评分、贪心调度、餐饮插入和文本检索，为用户生成结构化旅行计划，并通过 OpenAI/DeepSeek 兼容接口或本地模板生成中文行程解释。

## 项目职责

- 设计 POI 与通勤边数据模型，将开放时间、游玩时长、兴趣标签、热度和消费水平纳入规划约束。
- 实现基于 Dijkstra 的 POI 最短通勤时间计算，并在行程评分中加入距离惩罚。
- 设计多目标评分函数，综合兴趣匹配、必去景点、热度、价格、时间窗和用户节奏生成候选安排。
- 实现多日贪心调度与午餐/晚餐时间窗插入，输出每天上午、午餐、下午、晚餐、晚上活动。
- 实现轻量 POI 文本检索和 LLM/模板解释层，支持无 API Key 环境下稳定演示。
- 使用 `cpp-httplib` 提供 `/trip/plan`、`/poi/search`、`/route/shortest`、`/trip/alternatives`、`/itinerary/explain` 和 `/health` HTTP JSON API。
- 构建本地 Web 演示台，展示偏好输入、候选行程、路径耗时、替换方案和自然语言解释，便于面试现场演示。
- 输出优化前后通勤时间对比、约束命中说明和未安排原因，增强规划结果的可解释性。

## 项目亮点

项目把图搜索、时间窗调度、多目标排序和大模型解释生成结合起来，解决自由行规划中“去哪玩、怎么排、去哪吃、时间是否够用”的实际问题；核心规划模块可作为独立 C++ 算法服务接入旅游类后端系统。
